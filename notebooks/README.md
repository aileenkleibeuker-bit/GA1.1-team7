## `subtract(a, b)`

Subtracts `b` from `a` and returns the result.

### Parameters
- `a` (int or float): the number to subtract from
- `b` (int or float): the number to subtract

### Returns
- The result of `a - b`

### Example

```python
subtract(10, 4)  # 6
subtract(5, 5)   # 0
subtract(3, 8)   # -5
```
## `add(a, b)`

Adds `a` and `b` and returns the result.

### Example
```python
add(2, 3)  # 5
```

## `sum_list(values)`

Sums all numbers in a list and returns the total.

### Example
```python
sum_list([add(2,3), add(4,5), add(6,1)])  # 21
```
